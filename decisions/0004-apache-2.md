# 0004: Apache 2.0 licence

Status: accepted · 2026-10-20

## Decision
License MDS under Apache 2.0. Accept only dependencies with compatible licences
(MIT, BSD, Apache, ISC, PSF).

## Consequences
- Maximum adoption and an explicit patent grant.
- Anyone, including hosting providers, may run and modify it.
- Contribution model (DCO or CLA) to be decided before accepting outside contributions.
